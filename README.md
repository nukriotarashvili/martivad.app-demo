## მეთოდოლოგია

* ანგარიშთა გეგმა — საქართველოს ბუღალტრული აღრიცხვის სტანდარტების 9-კლასიანი გეგმა (114 ანგარიში).
* აღრიცხვა — IFRS for SMEs, დარიცხვის მეთოდი.
* სასაქონლო მარაგი — საშუალო შეწონილი, პერიოდული (§13.18); პერიოდი კალენდარული თვეა.
* უცხოური ვალუტა — ანგარიშიდან გასვლა მოძრავი საშუალო კურსით; წინასწარი გადახდა
  არამონეტარულია და ფიქსირდება გადახდის კურსით (§30.9).
* დღგ — განაკვეთი ორგანიზაციის პროფილში, ნაგულისხმევად 18% (სსკ მუხ. 168).

## ტექნიკური მხარე

არანაირი build, არანაირი დამოკიდებულება — მხოლოდ სტატიკური ფაილები:

```
index.html
assets/
  app.js         ინტერფეისი (ES module)
  store.js       ორგანიზაციების საცავი (localStorage)
  importers.js   ამონაწერი და რეალიზაციის რეპორტი → გატარებები
  sheetread.js   .xlsx (ZIP+XML), .xls (OLE2+BIFF8) და .csv წამკითხველი
  coa.js         ანგარიშთა გეგმა
  styles.css     გაფორმება (ღია და ბნელი თემა)
```

`sheetread.js` ექსელის ფაილებს ბრაუზერშივე შლის — `.xlsx` ZIP-ის სახით
(`DecompressionStream`), `.xls` კი OLE2 კონტეინერიდან BIFF8 ჩანაწერების დონეზე.
გარე ბიბლიოთეკა არსად არ გამოიყენება.

### ლოკალურად გაშვება

```bash
git clone https://github.com/nukriotarashvili/martivad.app-demo.git
cd martivad.app-demo
python3 -m http.server 8000
# გახსენით http://localhost:8000
```

ES module-ების გამო `index.html`-ის პირდაპირ ფაილიდან გახსნა (`file://`) არ მუშაობს —
საჭიროა ლოკალური სერვერი.

### ჰოსტინგი

`main` ბრენჩში ატვირთვისთანავე GitHub Actions აქვეყნებს GitHub Pages-ზე
(იხ. `.github/workflows/pages.yml`). სხვა სტატიკურ ჰოსტინგზეც (Netlify, Vercel,
Cloudflare Pages) უბრალოდ საქაღალდის ატვირთვა კმარა.
